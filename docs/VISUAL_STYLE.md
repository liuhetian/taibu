# 视觉系统：天象档案

## 母风格

所有位图共享一套原创视觉语言：

- 深靛黑手工纸与轻微纤维；
- 哑光矿物颜料；
- 旧金精密线条；
- 朱砂、青玉、暖象牙白作为受控点色；
- 安静、明亮但不恐怖；
- 保持足够留白，便于未来网页裁切和叠加界面。

母图是 `assets/style/style-anchor.png`。它只定义材质、颜色、光感和精度，
不规定每条管线必须使用圆盘。

## 生产规则

1. 每个不同资产使用独立 imagegen 调用。
2. 禁止搬运、描摹或拼贴参考仓库、现有塔罗牌或宗教签谱图片。
3. 位图内不放标题、数字或可读文字；文本由未来 UI 渲染。
4. 人物相关主题优先用尊重的象征静物，不生成冒充宗教权威的肖像。
5. 最终提示词必须存入 `assets/prompts/`。
6. 每个可发布文件必须登记 SHA-256。
7. `uv run suanming assets --verify` 必须全绿。

## 资产契约

运行结果只返回相对路径：

```json
{
  "id": "ziwei.cover",
  "pack": "ziwei-v1",
  "role": "pipeline-cover",
  "path": "assets/packs/ziwei/cover.png",
  "media_type": "image/png",
  "status": "available"
}
```

网页层可以把相对路径映射到 CDN；CLI 和 Python 内核不假设部署域名。

## 继续扩展

新增视觉包时先决定一个与现有管线不同的主轮廓，再继承母风格。不要仅靠换色区分。
若生成卡牌系列，先制作构图模板与卡背，再逐张生成，并把每张图片作为独立资产登记。
