# Expansion cover prompts

Mode for every generation: built-in `imagegen`.

Style reference for every new cover:
`assets/style/style-anchor.png`.

Each heading names the repository target. Every fenced block is the exact prompt
used for that generation. Generated source files are retained in Codex's generated
image directory; this repository contains copied project-bound assets.

The initial output contained two distant silhouettes, so the final asset was
created with this exact image-edit prompt:

```text
Edit this generated square illustration while preserving the composition, color, lighting, tools, open blank manual, central wood joint, and all visual texture exactly as much as possible. Remove every tiny human silhouette or human-shaped figure from the far left and far right background courtyard. Replace those figures seamlessly with empty stone paving, workshop architecture, and soft lantern light. Keep the scene entirely unoccupied. Add no text, no logo, no watermark, and make no other substantive changes.
```
